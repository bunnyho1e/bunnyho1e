# bunnyho1e

### Think like an attacker. Build like an engineer. Automate the rest.

Building tools, AI prompts, and workflows for **red teaming, penetration testing, and offensive security research**.

## Focus

- **Red Teaming** — adversary simulation, attack path research, and practical tooling.
- **Pentesting** — web, API, mobile, and identity security.
- **AI & Agents** — prompts, agents, and integrations that support security testing.
- **Automation** — scripts and workflows that cut repetitive work and connect the tools.

From reconnaissance to reporting: sharper testing, repeatable workflows, and findings backed by evidence.
